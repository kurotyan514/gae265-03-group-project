## 判定方式

見 `src/insurance_agent/rag/evaluate.py` 的 `is_pass`：`expect` 的每一項，前 k 筆結果中都要有一筆**公司相同**、且**標題＋內文含有 `text_has`**。

## 出題原則

- 題目用一般旅客的口語（例如「自行車比賽」「手機被扒」「打仗」），刻意不照抄條文用語（條文是「自由車」「行動電話被竊」「武裝變亂」），這樣才測得出檢索能不能跨過用詞落差。
- `text_has` 選該條文才有、有辨識力的片語，避免「戰爭」「申請書」「二年」這種在幾十段都出現的字。下表「符合段數」是該公司在 `data/processed/chunks.jsonl` 中含有該字串的段數。
- PDF 轉文字會在行尾斷行，`text_has` 一律選同一行內連續出現的字串（例如富邦旅程取消的「無法取\n回之預繳團費」就只取「預繳團費」）。
- 條款沒有寫到的活動不出題。**高空彈跳、跳傘**在兩家條款中都找不到任何字樣，所以沒有出題，免得變成量不到東西的題目。休閒潛水也一樣，兩家都沒有明文，只有國泰把「職業潛水」列為海上工作的除外責任（q24），所以 q24 只要求國泰。
- 只有一家有對應條文時，`expect` 只列那一家（q24），不硬湊另一家。

## 各題依據

條文 id 為 chunks.jsonl 的 `id` 去掉公司前綴，格式是「商品|條號」。

## 建題時的基準（僅供參考）

這是口語題目的真實難度，沒有為了提高分數改題目或改 `text_has`。vector／hybrid 的結果由實驗框架另外跑。
