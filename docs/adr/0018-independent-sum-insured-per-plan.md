# 推薦後兩個方案各自選保額；推薦不看年齡與目的地

[ADR-0017](0017-recommendation-rule.md) 規定推薦後兩個方案共用同一個保額、只能選兩者都可投保的範圍。換成九個方案後各家可投保的保額差很多（富邦 600–1,000 萬、華南只有 300／500／800／1,000 萬），交集常常只剩一兩個，甚至沒有。改為推薦方案與對照方案各自列出自己可投保的保額、各自選，互不影響；改保額仍只重算該方案的保費與額度，不重新推薦，推薦理由維持以推薦保額計算的內容。

- **推薦不看年齡與目的地**：保費資料（[ADR-0016](0016-plan-premiums-from-einsure-sheet.md)）沒有年齡維度、只有日本，推薦的輸入只有天數與排序過的在意事項；ADR-0017 的「年齡可投保的方案」等有年齡資料再加。
- **同一層級保費相同**：照 `plans.json` 的順序取第一個，同樣的輸入一定得到同樣的結果。
- **天數**：只有 4–10 天有報價，前端的日期只能選出 4–10 天；後端收到範圍外的天數回錯誤，不推估。

## Considered Options

- **維持共用保額、取交集**（ADR-0017 原規則）：兩欄比較時保額一致、比較公平，但交集太小，使用者常常沒得選。
- **共用保額、取聯集，沒有報價的方案顯示「無報價」**：選項多，但選完常有一邊是空的。
